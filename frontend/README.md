# DemoEnglish — frontend

Cliente React (Vite + TypeScript + Tailwind) para búsqueda en el diccionario y gestión de mazos Anki.

Instrucciones de desarrollo, variables de entorno y descripción de funciones están en el **[README del repositorio](../README.md)**.

Comandos habituales:

```bash
npm install
npm run dev
npm run build
```
